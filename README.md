# Pathfinding and Search Algorithms
A collection of Python implementations exploring graph search, shortest-path computation, and constraint-solving techniques.

This university group project brings together three algorithmic problems: Dijkstra's shortest path algorithm for weighted graphs, a recursive backtracking solver for Sudoku, and A* pathfinding across grids with obstacles and weighted terrain. The implementations explore algorithm design, data structures, heuristic search, input validation, and the trade-offs between search efficiency and solution quality.
