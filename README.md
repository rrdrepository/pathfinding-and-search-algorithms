# Pathfinding and Search Algorithms

A collection of Python implementations exploring graph search, shortest-path computation, and constraint-solving techniques.

This university group project brings together three algorithmic problems: Dijkstra's shortest path algorithm for weighted graphs, a recursive backtracking solver for Sudoku, and A* pathfinding across grids with obstacles and weighted terrain.

The implementations explore algorithm design, data structures, heuristic search, input validation, and the trade-offs between search efficiency and solution quality.

## Algorithms Implemented

### 1. Dijkstra's Shortest Path Algorithm

Computes shortest paths in weighted graphs using a greedy approach. The implementation supports directed and undirected graphs and presents the graph representation, selection process, and resulting paths.

### 2. Sudoku Solver

Solves 9×9 Sudoku puzzles using recursive backtracking. The solver checks row, column, and 3×3 box constraints while searching for a valid solution.

### 3. A* Grid Pathfinding

Searches for paths through grids containing obstacles and weighted terrain. The implementation explores different heuristics and movement options, using a custom binary min-heap to manage candidate nodes.

## Technologies and Concepts

- **Language:** Python
- **Graph algorithms:** Dijkstra's shortest path algorithm
- **Search:** A* heuristic search
- **Constraint solving:** Recursive backtracking
- **Data structures:** Graph representations and a custom binary min-heap
- **Additional concepts:** Input validation, path reconstruction, and search-performance analysis

## Project Context

Developed as a university group project for Data Structures and Algorithms. The project involved implementing and evaluating multiple algorithmic approaches to graph search and constraint-solving problems.
